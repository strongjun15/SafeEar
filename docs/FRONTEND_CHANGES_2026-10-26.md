# SafeEar 프론트엔드 수정사항

작업일은 2026년 10월 26일이며, 대상 브랜치는 sunjae0721이다. 아래 내용은 이번 작업의 최종 화면과 동작을 기준으로 정리한 것이다.

## 로그인, 회원가입

- 로그인 없이 사용하는 진입 버튼을 제거한 상태이다.
- 로그인 화면의 회원가입 하기 링크로 가입 화면에 진입하는 구조이다.
- 회원가입에 이름, 아이디, 만 나이, 이메일, 비밀번호, 비밀번호 확인, 필수 동의를 받는 구조이다.
- 비밀번호 확인 입력 시 일치 여부를 즉시 표시하는 방식이다.
- 인증코드 입력과 재발송 화면은 제거한 상태이며, 가입 후 바로 로그인하는 흐름이다.
- test11 / test11은 샘플 기록과 가상 장치가 있는 데모 계정이다.
- test / test는 기록과 연결 장치가 없는 일반 사용자 화면 테스트 계정이다.
- 테스트 계정 상태는 실제 인증과 분리된 메모리 안에서 동작하며 서버로 전송하지 않는 구조이다.

## 첫 실행 안내, 알림

- 튜토리얼 순서는 앱 설명, 회복과 리포트 안내, 알림 권한, 시작 화면 순서이다.
- 알림 허용 처리가 완료되면 다음 단계로 이동하는 방식이다.
- 다시 보지 않음은 기기 안에 계정별로 저장되는 설정이다. 선택하지 않으면 로그인할 때마다 나타나는 동작이다.
- 기타 메뉴에서 튜토리얼을 다시 여는 기능이 추가된 상태이다.
- 기록할 출력 장치가 없으면 위쪽에 장치 연결 안내를 표시하는 방식이다. 장치 연결, 직접 닫기, 표시 후 5초 경과 중 하나가 발생하면 사라지는 동작이다.

## 홈

- 제목은 SAFEEAR이며 테마에 맞춰 색상을 바꾸는 방식이다. 글꼴은 기존보다 둥근 인상의 Gowun Dodum과 Nunito를 사용하는 구성이다.
- 파란 카드에는 오늘 청취 부담, 작은 주간 청취 부담, 100% 도달 예상, 기록 정지와 재개 버튼을 배치한 상태이다.
- 일시정지 안내를 크게 보여주면서 오늘 쌓인 수치도 유지하는 구조이다.
- 기존 피로 곡선과 오늘 남은 허용량은 제거한 상태이다.
- 실시간 추정 음량, 재생 앱, 기기 볼륨, 분당 청취 부담 증가 속도를 표시하는 구성이다.
- 현재 기준 음량 초과 또는 현재 속도로 30분 안에 오늘 기준 100%에 도달하는 경우 경고 팝업을 표시하는 방식이다. 확인한 경고는 같은 조건에서 반복하지 않는 구조이다.
- 오늘 누적 청취 부담이 80% 이상일 때 회복 버튼을 연한 주황 계열로 표시하는 방식이다.
- 프로필 버튼은 화면 내용과 함께 스크롤되는 배치이다.

## 귀 지도

- 막대그래프를 귀여운 달팽이 그림 위의 주파수별 부담 표시로 바꾼 상태이다.
- 낮은 소리와 높은 소리의 위치를 그림 안에 표시한 상태이다.
- 소리별 부담 비중은 도넛형 원 그래프로 표시하며, 가운데에는 부담이 가장 큰 소리 종류를 표시하는 구성이다.
- 색 범례와 필요한 라벨은 유지하고 장황한 설명 문단은 제거한 상태이다.

## 회복

- 현재 부담과 기존 회복 계산 결과를 사용해 시간 선택지에 추천 배지를 붙이는 방식이다.
- 별도 추천 설명 문단은 제거한 상태이며 기존 회복 타이머는 유지한 구성이다.

## 청취 부담 리포트

- 청취 시간 대신 누적 청취 부담 비율을 주요 수치와 막대그래프로 표시하는 구성이다.
- 일별과 주별 선택, 이전과 다음 기간 이동을 제공하는 방식이다. 날짜에서 연도는 제거한 상태이다.
- 주간 막대를 누르면 해당 날짜의 일별 기록으로 이동하는 구조이다.
- 마우스, 터치, 키보드 포커스에 따라 막대 위 작은 말풍선에 부담 비율과 청취 시간을 표시하는 방식이다.
- 그래프 눈금과 높이를 같은 기준으로 맞추고 시간 반올림도 정리한 상태이다.
- 하단의 하루 기준 기여도와 합산 설명 문구는 제거한 상태이다.
- 선택한 날짜의 기록을 집계하는 getReport와 공통 집계 함수를 추가한 상태이다.

## 10년 뒤

- 지금 습관 유지와 음량을 3 dB 낮춘 경우를 한 그래프에서 비교하는 구성이다.
- 세로축은 청력 역치 상승 (dB)이며, 기존 계산 결과를 사용하는 방식이다.
- 예상 청력 변화 표와 무엇이 먼저 흐려지나 항목, 중복 설명 문단은 제거한 상태이다.
- 그래프 아래에는 음량을 낮췄을 때 예상 손실 차이를 한 줄로 표시하는 방식이다.
- 데모 계정에는 85 dB와 82 dB의 가상 시나리오를 넣어 두 선의 차이를 확인할 수 있는 상태이다. 실제 기록과 무관한 예시 표시가 있는 구성이다.
- 원래 소리와 두 가지 습관의 소리를 비교하는 기능은 유지한 상태이다.

## 내 정보 및 설정

- 내 기기 목록, 측정, 동기화, 알림 설정 항목을 제거한 상태이다. 동기화와 알림 종류는 기본 활성 상태이며 실제 알림은 권한 동의 후 요청하는 구조이다.
- 기타에는 앱 정보, 내 기록 내보내기, 기록 지우기, 튜토리얼 보기를 배치한 상태이다.
- 로그아웃과 회원 탈퇴는 가장 아래에 배치한 상태이다.
- 프로필 사진을 선택하고 변경하는 기능이 추가된 상태이다. 사진은 256픽셀 정사각형으로 줄여 기기에 계정별로 저장하는 방식이다.

## 백엔드 연결과 후속 확인

- 실제 가입과 로그인에는 Supabase 연결이 필요한 상태이다. 가입 직후 로그인하려면 서버의 이메일 확인 설정을 꺼야 하는 구조이다.
- 아이디는 username 메타데이터로 전달하는 상태이며, 실제 아이디 중복 검사와 아이디 로그인 조회는 백엔드 연결이 필요한 항목이다.
- 만 나이는 age 메타데이터로 저장하고 기존 계산과 호환되는 age_band로 변환하는 방식이다.
- 프로필 사진의 다른 기기 동기화는 아직 연결하지 않은 상태이다.
- 홈 주간 수치는 기존 standardPct를, 리포트 부담은 첨도 보정 선량을 사용하는 상태이다. 서비스 연동 시 두 화면의 지표 정의를 통일할 필요가 있는 항목이다.
- 실제 Windows 소리 캡처, 운영체제 알림 권한, 실제 계정 동기화와 이메일 인증 설정은 서버와 실행 환경에서 추가 검증이 필요한 항목이다.
- 상세 계정 연동 내용은 [FRONTEND_AUTH_HANDOFF.md](FRONTEND_AUTH_HANDOFF.md)에 정리한 상태이다.

## 검증

- 기존 core 테스트 34개가 통과한 상태이다.
- TypeScript 타입 검사와 데스크톱 빌드, 브라우저 미리보기 빌드를 확인한 상태이다.
- 브라우저에서 로그인, 비밀번호 확인, 튜토리얼, 기록 정지와 재개, 리포트 날짜 이동과 말풍선, 프로필 사진 변경, 팝업 닫기와 5초 자동 종료를 확인한 상태이다.
- 별도 집계 검증으로 날짜 경계, 시간 반올림, 일별과 주별 시간 일치, 동일한 청취 시간에서 서로 다른 부담, 부담 합산을 확인한 상태이다.
- 실제 서버와 실제 Windows 장치에 대한 통합 테스트를 완료했다는 의미는 아닌 상태이다.
